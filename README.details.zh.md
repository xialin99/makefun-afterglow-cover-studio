# 余晖封面工作室

可直接打开 app/index.html。先选一个画格，再用文件选择器更换图片，也可把图片拖到预览。拖动调整构图，滑块调整缩放。选择「用于全部画格」后，仍可逐个修改构图。导出支持横版 1920 × 1080、方形 1080 × 1080、竖版 1080 × 1350。

## 技术说明

渲染与示例图位于 app/。字体附 OFL 许可。图片处理和 PNG 编码均在浏览器内完成。使用 Node.js 22.18 或以上运行 main.ts 可打包赛事提交。输出目录由 MAKEFUN_OUTPUT_DIR 指定。
